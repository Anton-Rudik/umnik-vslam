# UMNIK V-SLAM

**Автономная визуальная навигация роботизированных платформ на основе стереозрения**

*Autonomous visual navigation for robotic platforms using stereo vision and V-SLAM.*

> Статус: исследовательская стадия. Характеристики ниже — **целевые требования**, а не подтверждённые результаты.

## О проекте

Проект посвящён исследованию и разработке аппаратно-программного комплекса визуальной навигации для роботизированных платформ в условиях отсутствия сигналов GNSS. Предполагается объединить пассивный стереоскопический сенсор, бортовой вычислительный модуль (edge) и алгоритмы визуальной одометрии/V-SLAM.

## Цели исследования

- Изучить алгоритмы компьютерного зрения и фильтрации динамических помех.
- Разработать и проверить базовую модель визуальной одометрии в шести степенях свободы (6-DoF).
- Спроектировать архитектуру компактного вычислительного модуля со стереосенсором.
- Выполнить эксперименты в симуляционной среде и оценить точность и вычислительные задержки.

## Планируемые характеристики

| Параметр | Целевое значение по техническому заданию |
|---|---|
| Обработка стереопотока | не менее 30 кадров/с |
| Вычислительная задержка одометрии | не более 50 мс |
| Погрешность позиционирования | не более 2 % пройденной дистанции (подлежит уточнению методика оценки) |
| Режим работы | без использования GNSS |

Эти показатели пока не подтверждены испытаниями готового аппаратно-программного комплекса.
